# Somewhere in Berlin

我的交換生活紀錄：攝影、旅行、插圖。
Photos, trips and drawings from my exchange year in Berlin.

## 資料夾說明
- `index.html`：網站首頁（版面結構）
- `assets/css/style.css`：樣式（顏色、字體、卡片外觀）
- `assets/js/data.js`：**內容區**，換照片、標題、插圖都改這裡
- `assets/js/main.js`：功能（切換語言、換頁、放大照片）
- `images/`：photo 攝影、trip 旅行封面、art 插圖、decor 首頁裝飾
- `trips/`：每趟旅行的遊記頁面
